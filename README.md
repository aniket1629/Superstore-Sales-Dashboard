# Superstore Sales Dashboard

## Project Overview

An Excel-based sales analytics dashboard built using the Superstore dataset to analyze sales, profit, order volume, regional performance, category performance, monthly trends, and top-performing products.

## Objective

The objective of this project was to transform raw transactional sales data into a clean, structured dataset and create an interactive dashboard that provides useful business insights.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- XLOOKUP
- SUMIFS
- COUNTIFS
- Excel Tables
- Data Cleaning
- Data Visualization

## Data Cleaning

The following steps were performed:

- Preserved the original dataset as Raw Data
- Removed duplicate records
- Removed incomplete records
- Converted Order Date into a proper date format
- Created an Excel Table named SalesData
- Checked missing values and data consistency

## Calculated Columns

- Profit Margin
- Year
- Month
- Order Size
- Manager

## KPIs

| KPI | Value |
|---|---:|
| Total Sales | 2,297,201 |
| Total Profit | 286,397 |
| Order Records | 10,296 |
| Profit Margin | 12.47% |

## Analysis

The dashboard analyzes:

- Sales and profit by region
- Sales by category
- Monthly sales trends
- Top 10 products by sales

## Key Insights

- West region generated the highest sales and profit.
- Office Supplies had the highest order volume.
- Total sales were approximately 2.30M with approximately 286K profit.
- Overall profit margin was approximately 12.47%.
